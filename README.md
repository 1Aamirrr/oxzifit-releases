# OXZIFIT for Android — downloads

This repository only hosts the OXZIFIT Android app (APK) for download. The app's source code is private.

**Get the app:** https://oxzifit-website.vercel.app — tap *Download for Android*, then follow the install steps there.

Every release is signed with the same OXZIFIT key, so updates install over the previous version and keep your data.
Download only from the website or this page's Releases section.
